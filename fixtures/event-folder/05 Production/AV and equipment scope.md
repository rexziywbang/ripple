# AV and equipment scope

Owner: Production · Working requirements

## Minimum useful setup

- One microphone appropriate to the room and audience size.
- A display or projector visible from the seating layout.
- Audio output if the final presentation includes sound.
- A supported connection for the presenter's laptop.
- Power at the presentation position, with cables kept out of walking routes.
- An offline copy of the slides and printed presenter notes.

A small dinner may work without amplification or projection. Discuss the actual program and room before keeping an equipment package designed for a much larger audience.

## Venue equipment comparison

Match equipment item by item. A television does not automatically replace a projector for a wide room. A venue's sound system may need an operator, an adapter or a separate microphone. Published availability is useful research; date-specific availability and charges remain separate questions.

## Rental baseline

The fictional September rental package was $1,800 for projector, microphones and sound, through logistics@brightav.example. The scenario allows cancellation without penalty after an equivalent setup is established. Later changes in the current budget may alter the retained amount.

Do not assume the rental has been canceled because the venue includes some AV. Prepare the comparison, obtain the missing scope if necessary and review the cancellation separately. Avoid a second rental request if the first one is still active.

## Event-day check

Test a slide with small text from the farthest seat. Run the exact presentation file, test the microphone where the speaker will stand and agree who advances slides. Complete the noisy setup before food receipt and guest arrival if one person covers multiple roles.
